# Evidence Tags

## Purpose
Make it impossible to present a from-memory claim as a verified one — in recurring reports, briefs, watch alerts, and research deliverables.

## The tags
Tag every decisive claim about prices, statuses, and deadlines:

- **[verified this run]** — checked against the primary source during this run.
- **[from-memory]** — recalled from notes or earlier work, not re-checked.
- **[unverified]** — asserted without a checkable basis. Use sparingly, and only labeled.

## Per-claim definitions
The tag is only honest with a concrete definition per claim type:
- **Price**: read from the retailer's own product page this run — not a search snippet, not a cached figure.
- **Delivery status**: carrier tracking cross-checked against confirmation emails this run; on disagreement, the emails win.
- **Needs-reply**: the full thread and sent mail were searched this run.

Each tag carries source plus read time so it can be spot-checked later. A claim tagged from-memory is not a lie — it's a claim with its uncertainty labeled, which is what makes the verified ones trustworthy.
