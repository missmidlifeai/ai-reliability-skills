# AI Reliability Skills

A collection of operating disciplines for AI assistants doing real work — verification gates, correction loops, and memory hygiene. The premise: the model supplies judgment, the harness supplies discipline. Neither works alone.

These were developed over months of daily use with a personal AI assistant and hardened by every failure. Each skill is self-contained: the problem it solves, when to use it, and how to run it.

## The skills

1. **verify-before-you-speak** — Quote the primary record before any status claim. A partial read is labeled unverified, never presented as fact.
2. **two-stage-sourcecheck** — A publication gate: every quoted claim checked twice by deterministic code (verbatim, then support). Fails closed.
3. **pre-send-gate** — A checklist before any one-off deliverable goes out: everything asked is answered, every number is quoted, every judgment call named.
4. **read-back-verification** — Nothing counts as set up until it has been verified in the roster. A recurring job names its write-back path at creation.
5. **correction-loop** — Log every correction the same day with root cause; patterns that recur graduate from written rules to enforced checks.
6. **async-followup-protocol** — Check-backs for delegated work: 30 min, 60 min, then hourly, with a stop condition. Always schedule both early checks up front.
7. **evidence-tags** — Tag decisive claims as verified-this-run, from-memory, or unverified — with per-claim definitions of what each tag requires.
8. **recusal-and-evaluation** — Before scoring or judging anything, check independence; then run the six-question evaluation card.
9. **build-discipline** — One-sentence intent before building, research before novel setups, a mid-task checkpoint, and built ≠ done.
10. **discussion-vs-decision** — Keep exploration labeled exploration. Never execute on a brainstorm.
11. **memory-budget** — Zero-sum long-term memory, quote-backed candidate learnings, backtest before adopting rules.

## Using these

Each folder holds a `SKILL.md` with the full method. Adopt one at a time — a rule that ships with a replay of the failures it targets is worth ten that sound good.
